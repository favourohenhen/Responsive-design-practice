# Responsive Design Practice

This project is a small collection of front-end exercises focused on responsive layouts, media queries, and modern landing page design. It includes two demo pages that showcase different approaches to mobile-first and adaptive styling.

## Project Overview

The workspace contains:

- `apex-tech-website/` — a dark-themed tech landing page styled as a modern gadget and gaming brand website.
- `media-queries/` — a simpler responsive layout demonstration that explores media-query behavior and grid-based structure.

## Included Demo

### Apex Tech Landing Page

A polished landing page for a fictional tech brand called Apex Tech. It includes:

- Fixed top navigation
- Hero section with call-to-action buttons
- Bento-style image and video gallery
- Responsive design for desktop and mobile screens
- Gradient branding and modern UI styling

### Media Queries Demo

A learning page built to practice:

- CSS Grid layout
- Media queries
- Responsive typography and spacing
- Sidebar layout behavior at different screen widths
